Open Agent Hackathon 2026 · GenAI.Works · Track “The Agent That Can Explain Why”

3NET News Agent

A weekly agent that reads the public Microsoft 365 Roadmap, filters out what is irrelevant with transparent rules, scores the rest with NVIDIA Nemotron, remembers what was already reported – and gives a reason for every decision. A person reviews the result before anything goes to customers.

  • Rule-based prefilter, model scoring and memory – each step explained in the report
  • Newsletter draft for review, with scores and reasoning
  • Ports-and-adapters architecture: new sources without new code paths
  • 126 tests without network access; H-MEM conformance 13/13
